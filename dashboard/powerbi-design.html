Diseño del tablero de Power BI: facturas que se cargan solas al ERP, con lo que no cierra a revisión

Guía para armar el informe en Power BI Desktop a partir de los archivos Parquet de outputs/powerbi: modelo, relaciones, consultas, medidas y las cinco páginas con una vista previa de cada visual dibujada con las cifras exportadas. Datos sintéticos salvo CORD: las facturas, órdenes, remitos, proveedores y CUIT son sintéticos; los recibos de CORD son reales.

Cómo armarlo en Power BI Desktop

  1. Instale Power BI Desktop (gratuito, solo para Windows) y abra un informe en blanco.
  2. Cree un parámetro de texto llamado CarpetaSalidas con la ruta de outputs\powerbi.
  3. Cree una consulta por tabla (20) con el código de la sección «Power Query»; deje el nombre de la consulta igual al de la tabla.
  4. En la vista de modelo, cree las 17 relaciones de la tabla «Relaciones»: uno a varios (1:*), filtro único de la dimensión al hecho, todas activas. Los hechos sin clave compartida (fact_choice, fact_evaluation_summary) no tienen relación: alimentan sus propios visuales, y fact_invoice_reason se relaciona solo con los motivos (no hay una dimensión de facturas).
  5. Marque dim_date como tabla de fechas con la columna date; ordene dim_date[weekday_es] por date.
  6. Cree una tabla vacía llamada _Medidas y agregue en ella las medidas de la sección «Medidas DAX», con su formato.
  7. Cree las 5 páginas a 1280 × 720 px y ubique cada visual según la grilla de 12 columnas por 9 filas; ponga en cada una la leyenda «Datos sintéticos salvo CORD».
  8. Guarde el informe como .pbix. Cuando corra el flujo, «Actualizar» vuelve a leer los mismos archivos.
Qué se probó y qué no. Las pruebas del proyecto comprueban que los archivos cumplen el modelo (claves únicas, claves foráneas en su dimensión, relaciones de uno a varios con filtro único) y que cada tabla, columna, medida y función que nombra una expresión DAX existe, que las medidas de la prueba piden solo las filas selladas y que cada segmentador alcanza lo que dice filtrar. Ninguna medida se ejecutó: aquí no hay Power BI, y las vistas previas muestran las cifras de las tablas sin segmentadores. El .pbix se arma a mano siguiendo este documento.
Una cifra de las facturas es sintética y un tiempo es de procesamiento. Toda cifra que sale de las facturas generadas lo dice; «segundos por factura» es el tiempo que tarda el flujo en procesarla, no el tiempo de una persona. La prueba de CORD (recibos reales) se abrió una sola vez, en el cierre.

Medidas DAX

Todas van en la tabla _Medidas. Los nombres de las medidas y los textos están en español; las tablas y las columnas, en inglés. Las medidas que leen una tabla con seal_state piden solo las filas selladas: si no, una fila posterior al sello contaría dos veces o vaciaría la cifra.

Facturas

Facturas de los días elegidos, desde el seguimiento diario: existe antes del cierre y no depende de la prueba. Formato: #,0.

Facturas =
SUM ( fact_daily_ops[invoices] )

Cargadas solas

Facturas de los días elegidos que el flujo cargó solo. Formato: #,0.

Cargadas solas =
SUM ( fact_daily_ops[auto_post] )

A revisión

Facturas de los días elegidos que fueron a revisión. Formato: #,0.

A revisión =
SUM ( fact_daily_ops[review] )

Facturas de la prueba

Facturas de la prueba evaluada con la configuración sellada, en las cohortes y las clases elegidas. Formato: #,0.

Facturas de la prueba =
CALCULATE ( COUNTROWS ( fact_invoice ), fact_invoice[seal_state] = "sealed" )

Facturas a revisión de la prueba

Facturas de la prueba evaluada que fueron a revisión. Formato: #,0.

Facturas a revisión de la prueba =
CALCULATE ( COUNTROWS ( fact_invoice ), fact_invoice[decision] = "review", fact_invoice[seal_state] = "sealed" )

Paso directo (%)

Parte de las facturas sin discrepancia sembrada que se cargaron solas y bien (sintético). Formato: 0.0%.

Paso directo (%) =
DIVIDE ( CALCULATE ( COUNTROWS ( fact_invoice ), fact_invoice[straight_through] = TRUE (), fact_invoice[seal_state] = "sealed" ), CALCULATE ( COUNTROWS ( fact_invoice ), fact_invoice[planted_key] = "none", fact_invoice[seal_state] = "sealed" ) )

Cargas malas

Facturas cargadas solas con una discrepancia sembrada o con campos que no son los verdaderos (sintético). Formato: #,0.

Cargas malas =
CALCULATE ( COUNTROWS ( fact_invoice ), fact_invoice[bad_post] = TRUE (), fact_invoice[seal_state] = "sealed" )

Tasa de carga mala

Cargas malas sobre las facturas cargadas solas (sintético). Usa: [Cargas malas]. Formato: 0.0%.

Tasa de carga mala =
DIVIDE ( [Cargas malas], CALCULATE ( COUNTROWS ( fact_invoice ), fact_invoice[decision] = "auto_post", fact_invoice[seal_state] = "sealed" ) )

Líneas exactas (%)

Parte de las líneas leídas exactas, contra la verdad sintética. Formato: 0.0%.

Líneas exactas (%) =
DIVIDE ( CALCULATE ( SUM ( fact_invoice[lines_exact] ), fact_invoice[seal_state] = "sealed" ), CALCULATE ( SUM ( fact_invoice[lines] ), fact_invoice[seal_state] = "sealed" ) )

Segundos por factura

Segundos medios de procesamiento por factura de la prueba; no es el tiempo de una persona. Formato: 0.000.

Segundos por factura =
CALCULATE ( AVERAGE ( fact_invoice[seconds] ), fact_invoice[seal_state] = "sealed" )

Segundos p95 del día

Segundos del percentil 95 de los días elegidos: el mayor de ellos. Formato: 0.000.

Segundos p95 del día =
MAX ( fact_daily_ops[seconds_p95] )

QR leídos (%)

Parte de los QR impresos que se leyeron con el texto exacto (sintético). Formato: 0.0%.

QR leídos (%) =
DIVIDE ( CALCULATE ( SUM ( fact_qr_read[read_ok] ), fact_qr_read[seal_state] = "sealed" ), CALCULATE ( SUM ( fact_qr_read[printed] ), fact_qr_read[seal_state] = "sealed" ) )

Recuerdo del campo

Parte de las hojas que el modelo escribió y que se normalizaron a un valor (no dice si es el verdadero). Formato: 0.0%.

Recuerdo del campo =
DIVIDE ( CALCULATE ( SUM ( fact_field_read[correct] ), fact_field_read[seal_state] = "sealed" ), CALCULATE ( SUM ( fact_field_read[leaves] ), fact_field_read[seal_state] = "sealed" ) )

Carga mala de la línea base

Tasa de carga mala de la línea base (o del flujo) de la cohorte elegida, con la configuración sellada. Formato: 0.0%.

Carga mala de la línea base =
CALCULATE ( SELECTEDVALUE ( fact_baseline[bad_post_rate] ), fact_baseline[seal_state] = "sealed" )

TED de CORD

TED medio del modelo elegido o del checkpoint en la prueba de CORD, con la configuración sellada. Formato: 0.000.

TED de CORD =
CALCULATE ( SELECTEDVALUE ( fact_cord_eval[ted_mean] ), fact_cord_eval[field] = "all", fact_cord_eval[split] = "test", fact_cord_eval[seal_state] = "sealed" )

Veredicto

Veredicto de un criterio con la configuración sellada. Formato: @.

Veredicto =
CALCULATE ( SELECTEDVALUE ( fact_evaluation_summary[verdict_es] ), fact_evaluation_summary[seal_state] = "sealed" )

Última fecha de cálculo

Instante de cálculo de la última corrida terminada bien. Formato: yyyy-mm-dd hh:mm.

Última fecha de cálculo =
CALCULATE ( MAX ( dim_pipeline_run[as_of] ), dim_pipeline_run[status] = "ok" )

Reglas bloqueantes fallidas

Resultados de reglas bloqueantes que fallaron, en las corridas cargadas. Formato: #,0.

Reglas bloqueantes fallidas =
CALCULATE ( COUNTROWS ( fact_validation ), fact_validation[severity] = "bloqueante", fact_validation[status] = "falla" )
